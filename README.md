# Шарага Дроп (CASE DROP)

Браузерная игра с открытием кейсов в стиле CS:GO.

**[Играть онлайн](https://epictouch22.github.io/Sharaga-Drop/)**

## Что есть в игре
- 14 кейсов разной стоимости, со своими шансами и тематическими наборами оружия
- 108 скинов оружия и ножей, варианты износа
- Анимация открытия кейсов
- Инвентарь, продажа предметов, апгрейдер и контракты
- Flappy Bird для заработка внутриигровых денег ($3 за трубу)

Управление Flappy Bird: на компьютере — пробел или клик, на телефоне — касание экрана.

Сохранения хранятся в localStorage браузера. Деньги и предметы виртуальные, без вывода или реальной стоимости.

## Публикация
GitHub Pages автоматически разворачивается из `main` с помощью `.github/workflows/deploy.yml`.
